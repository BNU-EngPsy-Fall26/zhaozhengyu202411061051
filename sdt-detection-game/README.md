# 🌌 微光侦测站 · 信号检测论（SDT）互动实验

一个**纯前端**的信号检测论教学小游戏。你扮演深夜天文观测员，在布满噪点的夜空中判断每一次试次是否出现了微弱闪光。游戏结束后自动生成完整的信号检测论分析报告。

## ✨ 功能一览

### 1. 场景与参数定义
- 场景：微弱光点检测（经典心理物理学知觉研究范式）
- 可调参数：
  - **试次数**：每局 20 ~ 200（默认 40）
  - **先验概率 P(S)**：信号出现的概率（0.1 ~ 0.9）
  - **难度 d′**：滑块连续调节（0.3 ~ 3.5，步长 0.1）
  - **刺激呈现时长**：200 ~ 1500 ms
- 页面内以卡片形式说明**击中 / 漏报 / 虚报 / 正确拒斥**四种结果的实际含义

### 2. 交互式检测游戏
- 标准试次流程：注视点 `+`（700ms）→ 刺激呈现 → 作答（限时 3 秒，超时自动记为「没有」）→ 即时反馈
- 刺激由 Canvas 实时绘制：噪点星空持续闪烁，候选闪光亮度由该试次**真实采样的证据强度**决定（信号 ~ N(d′,1)，噪音 ~ N(0,1)）
- 支持鼠标点击按钮或键盘 `F`（有）/ `J`（没有）

### 3. 计算结果与展示
- 自动统计击中、虚报、漏报、正确拒斥（混淆矩阵）
- 自动计算并展示：
  - 击中率 P(Hit)、虚报率 P(FA)
  - **辨别力指数 d′** = Z(P<sub>Hit</sub>) − Z(P<sub>FA</sub>)
  - **判断标准 c** = −½[Z(P<sub>Hit</sub>) + Z(P<sub>FA</sub>)]
  - **报告倾向 β** = e<sup>d′·c</sup>
  - 准确率
- 采用 log-linear 校正（每格 +0.5）避免极端比例导致 Z 值发散
- 对 c 值给出通俗解读（保守 / 激进 / 中立）

### 加分项（已全部实现）
- 🧪 **SDT 概念可视化实验室**：双高斯分布图随 d′ 滑块实时变化，判断标准 c 可拖动，击中区/虚报区动态着色
- 📈 **ROC 交互可视化（与滑块联动）**：概率坐标 ROC 曲线 + 校正后 Z 变换直线（zROC，斜率 1、截距 = d′）双图并排；
  拖 d′ 看曲线整体抬升/直线上移，拖 c 看操作点沿曲线滑动，左右两图的对应点坐标实时显示
- 📈 **ROC 曲线**：理论曲线（按实测 d′ 绘制）+ 本局实测点 + 历史各局数据点
- 🏆 **多局对比与排行榜**：localStorage 本地存储最近 30 局，最佳准确率高亮
- 🎨 场景化 UI：观测员代入感、深夜星空 Canvas 动画、即时正误反馈

## 🚀 如何运行

无需任何依赖、无需后端、无需构建：

1. 克隆或下载本目录
2. **双击 `index.html`**，用浏览器（Chrome / Edge / Firefox）打开即可

```
sdt-detection-game/
├── index.html   # 页面结构
├── style.css    # 样式
├── script.js    # 游戏逻辑 + SDT 计算 + 可视化
└── README.md    # 本文件
```

> 提示：历史战绩存在浏览器 localStorage 中，清除浏览器站点数据会一并清空。

## 🧠 背后的理论

信号检测论假设：每次观察产生一个连续的「感觉证据」值。

- 噪音试次：证据 ~ **N(0, 1)**
- 信号试次：证据 ~ **N(d′, 1)**
- 观察者心中有一条判断标准 **x<sub>c</sub> = d′/2 + c**：证据超过它就说「有信号」

| | 你说「有」 | 你说「没有」 |
|---|---|---|
| **实际有信号** | 击中 Hit | 漏报 Miss |
| **实际无信号** | 虚报 FA | 正确拒斥 CR |

- **d′** 衡量你的感觉系统对信号与噪音的**辨别能力**（与主观标准无关）
- **c** 衡量你的**反应偏向**：c > 0 偏保守，c < 0 偏激进

本游戏的巧妙之处：每个试次的闪光亮度确实由对应分布中**随机采样**的证据值映射而来，所以你的每次犹豫，都是一次真实的信号检测过程。
